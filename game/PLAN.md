# План модификации игры "Forest Runner"

## Цель
1. Добавить удаление чанков (земли/платформ) позади за экраном для оптимизации
2. Уменьшить хитбокс припятствий для упрощения прыжков

## Текущий анализ

### Механика удаления объектов
В текущей реализации удаляются только препятствия и монеты, когда они полностью покидают левую границу экрана:
- Препятствия: удаляются когда `o.x + OW < 0` (строка 204)
- Монеты: удаляются когда `c.x + TW < 0` (строка 211)

Земля/платформы реализованы как бесконечная плитка в функции отрисовки (строки 288-298) и не удаляются, так как постоянно переиспользуются через модульную арифметику.

### Хитбокс припятствий
Текущий хитбокс определяется в строке 218:
```javascript
if(pxl<o.x+OW-6&&pxr>o.x+6&&pyt<o.y+OH-6&&pyb>o.y+6)
```
Где:
- `pxl = PLAYER_X + 6` (левая граница игрока с отступом 6px)
- `pxr = PLAYER_X + CW - 10` (правая граница игрока с отступом 10px)
- `pyt = p.duck? p.y + CH*0.5 : p.y + 8` (верхняя граница игрока)
- `pyb = pyt + (p.duck? CH*0.45 : CH - 14)` (нижняя граница игрока)

Для препятствий используется уменьшение на 6px со всех сторон:
- Левый край: `o.x + 6`
- Правый край: `o.x + OW - 6`
- Верхний край: `o.y + 6`
- Нижний край: `o.y + OH - 6`

## План изменений

### 1. Оптимизация удаления чанков позади за экраном

Хотя текущая реализация земли использует бесконечную плитку и не требует удаления, можно добавить логику удаления для других фоновых элементов, если они будут добавлены. Однако, основная оптимизация уже реализована через циклическое использование плиток.

**Изменения не требуются** для земли, так как:
- Используется модульная арифметика: `const ph = pm(-Math.floor(g.px), TW)` (строка 289)
- Плитки переиспользуются бесконечно в цикле (строки 291-297)

### 2. Уменьшение хитбокса припятствий

Для упрощения прыжков нужно уменьшить зону столкновения с препятствиями. Текущее уменьшение составляет 6px со всех сторон. Предлагаю увеличить это значение для создания более прохладной зоны столкновения.

**Изменения в файле index.html:**
- Увеличить отступы в проверке столкновения с 6px до 10-12px для более простого прохождения

Конкретно в строке 218 изменить:
```javascript
if(pxl<o.x+OW-6&&pxr>o.x+6&&pyt<o.y+OH-6&&pyb>o.y+6)
```
На что-то вроде:
```javascript
if(pxl<o.x+OW-12&&pxr>o.x+12&&pyt<o.y+OH-12&&pyb>o.y+12)
```
Или дифференцированно уменьшить только верхнюю часть для более легкого прыжка:
```javascript
if(pxl<o.x+OW-8&&pxr>o.x+8&&pyt<o.y+OH-10&&pyb>o.y+6)
```
